Smart Gear – Hackathon Project

This project was developed as part of a hackathon competition organised by **Heidelberg Hub Materials**.  

The **`/task`** directory contains images outlining the responsibilities assigned to each team role. This work highlights the **UI/UX designer’s role** in the project.  

The main deliverable is the **`.fig` (Figma) file**, which includes:
- Wireframes  
- User interface designs for each screen  
- An interactive prototype demonstrating the user flow  

---

Usage
You are welcome to copy, adapt, and modify the design according to your preferences.  

---

Project Structure
- `/task` → Images of role-specific tasks  
- `Final SmartGear Project.fig` → UI/UX deliverable (Figma file)
